# Frameworks

Public summaries of original operating frameworks.

## [Customer Outcome Reliability Model](./customer-outcome-reliability-model.md)

A post-sale operating framework for examining whether an organization can reliably turn what it promises customers into what customers actually experience.

```text
Promise
   ↓
Delivery
   ↓
Adoption
   ↓
Outcome
```

The public version shows the architecture, key questions, and common failure points while intentionally withholding detailed scoring, maturity logic, assessment mechanics, and remediation methodology.
