# Playbooks

Public pattern-recognition guides for recurring post-sale operating problems.

## [Outcome Reliability Failure Signals](./outcome-reliability-failure-signals.md)

A guide to signals that internal completion and customer reality may no longer match, including:

- green dashboards with unhappy customers
- closed tickets with unresolved problems
- implementation completion without adoption
- usage without demonstrable value
- cross-functional ownership gaps
- recurring escalations
- AI output without measurable improvement

The public playbook identifies the patterns. Detailed scoring, prioritization, root-cause mapping, and remediation logic remain private.
